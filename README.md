# thesvg-auth-badges-aegis

Full-color **2FA / Authenticator icon pack** built from theSVG Auth Badges, packaged for **Aegis Authenticator** and **Tokn** (Aegis pack.json format).

- **423 icons**, full color (no flat monochrome badges)
- Excludes crypto-exchanges / banks / universities / government brands
- Sources: theSVG color icons, Iconify (logos, selfhst, cbi, streamline-logos, token, cryptocurrency-color), dashboard-icons
- License: **CC0-1.0** (public domain)

## Install

1. Download thesvg-auth-badges-aegis.zip from the latest release.
2. Aegis: Settings -> Icon packs -> Import -> select the zip. Tokn reads the same Aegis pack.json format.

## Layout

- pack.json : Aegis manifest
- icons/ : 423 full-color SVG icons
